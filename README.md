This is a prosthetic hand made using anthropemetirc data found online in order to help those who do not have a hand.

The hand will be printed out of PLA (would be titanium if it werent a prototype) and use 5 micro gearmotors that sit inside of the palm that pull braided fishing lines to curl the fingers and elastic chords to open them.

To do this there are 2 6mm pipes going through each finger and the elasitc/ fishing line will be held with epoxy resin.
